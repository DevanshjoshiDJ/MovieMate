# ShadiSathi (React + Vite)

A prototype wedding operations app for:
- **Customers**: browse and book pandit, samagri, and venue services.
- **Pandit/Vendors**: manage service slots, stock, and booking workflow.
- **AI agents layer**: budget optimization, availability matching, and ritual checklists.

## Features in this prototype
- Unified booking catalog (pandit + samagri + venue)
- Date/city/service based availability filtering
- Instant booking list for customers
- Auto-generated AI plan suggestion under a configurable budget
- Dedicated vendor dashboard view

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
